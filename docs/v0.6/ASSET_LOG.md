The tool exposes neither a routing selector nor actual model/variant metadata; `image_gen¹` below is the verified generator, not a claim of verified Flare routing. No internet assets were downloaded.

Full prompts, reference intent, generation source paths and the six retained native source images: `UI_KIT_SOURCES.json` and `art-source/v0.6/ui-kit/`. Kit PNGs were component-sliced, trimmed, keyed, centered and resized with the existing Sharp pipeline; the three separate backgrounds are 1920×1080 WebP, quality 90. Sheet sources are 1254×1254 (normalized to 2048 for slicing); background sources are 1672×941. Each final image is unique. Text in contact sheets/demo is rendered by code, not embedded in any delivered kit image.
