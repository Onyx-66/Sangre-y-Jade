# Sangre y Jade v0.4.0

## Changes

- Arabic main menu mirrors the illustrated backdrop, moving the heroes to the left and leaving the menu on the right.
- Play now opens four separate steps: hero, map, mode, and attack controls/run summary. Back preserves choices; language switching preserves the current step.
- All runtime actor and effect animations load individual PNG frames. Skill icons are individually exported at 128×128 with an inset safety border, correcting atlas-neighbor fragments and clipped frames.
- Six new full-scene prologue illustrations replace crops from a composite sheet. The 27-second introduction retains progressive subtitles, skip/replay, and now includes bundled English male synthetic narration with ducked music. Sound requires a browser gesture; Enable Sound restarts the intro to keep narration aligned. Narration stops when skipped and pauses with a hidden tab.
- Arabic uses the bundled Unixel pixel font. Settings and language selectors use real SVG icons with accessible labels.
- Reworked health, magic, and dash-stamina meters. Stamina shows dash readiness, not a new resource affecting balance. The XP dock is shorter and placed low between joystick and skill controls; narrow portrait screens place it immediately above controls.
- Scenery instances vary in size. Pickups float inside pulsing colored bubbles and produce a collection burst.

## Art and source preservation

Generated artwork used built-in image generation. Exact prompts: `scripts/art-v04-sources.json`. Native originals: `art-source/v0.4/`; runtime panels: `public/assets/pixel/story-0.webp` through `story-5.webp`.

Combined actor/effect atlases were removed from the runtime folder after individual-frame export. Recoverable originals remain in `art-source/runtime-atlases/`; prior release ZIPs/APKs are retained. Frame manifest: `public/assets/pixel/asset-manifest.json`.

## Deliverables and limits

- Upload `release/Sangre-y-Jade-v0.4.0-itchio.zip` as an HTML game on itch.io; index.html is at its root. Enable mobile support and fullscreen.
- `release/Sangre-y-Jade-v0.4.0-Android.apk` is an offline debug-signed preview, not a Google Play production release. Production signing, store listing/review, and physical-device testing remain separate.
- Narration is English only; English, French, and Arabic subtitles/UI are available.
- The art is Maya-inspired fantasy, not an archaeological reconstruction. Translations and long-run balancing still benefit from native-speaker/player review.
- The supporter ZIP is a separate downloadable product. No live payment processing or in-app purchases are enabled.

Browser reports and screenshots are under `artifacts/v0.4/`; Android verification is under `artifacts/android-smoke-report.json`. See README for test/rebuild commands and `licenses/ASSET-PROVENANCE.md` for attribution.
