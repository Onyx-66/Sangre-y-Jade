# v0.5.0 — Flexible loadouts and support classes

## Setup and HUD

Removed numbered setup progress. Hero → map → mode → controls remain sequential. The panel uses a fixed footer row for Continue/Back and responsive card dimensions, with no scrolling across seven tested viewport sizes in English/French/Arabic. Skill replacement and support selection also fit small portrait/landscape screens.

Numbers normalize to Western 0–9, including literals inside Arabic translations. An isolated Latin digit font prevents the Arabic pixel font from substituting unfamiliar numeral glyphs. The pause button is a gold/obsidian SVG badge; cacao and kills have separate SVG symbols, labels, and high-contrast counters.

## Hero skills

Four active slots, bound to Q/E/R/T, alongside basic attack and dash. At full capacity the draft offers two equipped skills to upgrade and one new skill. Choosing the new skill opens a slot replacement screen; Cancel returns to the same draft. The new hero skill starts at rank 1. Skills capped at rank 6 are not offered as upgrades; stat choices fill unavailable upgrade positions. A full loadout is never permanently locked.

## Supports

After the hero's level-5 upgrade, recruit exactly one Saintess, Tank, or Assassin for that run. Each has ten skills; draft three initial skills. They operate automatically. All equipped skills gain a rank for each hero level, and later level-ups let you keep the loadout or replace one skill. Replacement support skills inherit the current support rank. The HUD support badge opens a loadout review.

- Saintess focuses on healing, shields, regeneration, mana, offensive/defensive buffs, and emergency rescue.
- Tank focuses on damage mitigation, projectile interception, proximity bombs, slowing traps, taunt, stuns, and protective shields.
- Assassin selects the highest-threat target within engagement range, weighting enemy damage, boss/ranged pressure, and proximity; it applies strikes, vulnerability, poison, bleed, silence, disarm, and smoke cover.

These are new generated characters with separate animation-frame files. Support ranks are independent of the hero-skill rank-6 cap. Supports currently persist without separate health bars. Skill icons/effect families reuse the game's existing art library. Long-run balance needs player testing.

## Pickups

XP, cacao and potions collect by touching/approaching them. Urns and baskets now also open on contact (attacking still works). Bubble cleanup, pickup bursts, and duplicate-collection guards remain in place.

## Distribution

`release/Sangre-y-Jade-v0.5.0-itchio.zip` is the HTML5 upload; `release/Sangre-y-Jade-v0.5.0-Android.apk` is an offline debug-signed preview. Old releases and original artwork are retained. This is not a production-signed Play Store release, and Android testing is on an emulator, not physical hardware.

Source art: `art-source/v0.5/`. Built-in generation prompt set: `scripts/art-v05-prompts.json`. Test reports/screenshots: `artifacts/v0.5/`.
